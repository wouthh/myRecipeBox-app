# myRecipeBox-app

> **Historical project**
>
> This application is historical, unmaintained, and not intended for deployment. Client configuration is embedded into frontend builds and is not confidential.
>
> Repository changes do not verify or secure the old backend. Provider-side database, storage, authentication, API restrictions, and authorized domains have not been reviewed. External service status and current compatibility have not been verified.

ReactJS. Résultat du troisième projet du tutoriel ReactJS pour débutants. Application permettant de créer, enregistrer et voir des recettes des personnes en utilisant une base des données commun (firebase) et en se connectant par un compte Facebook ou Twitter.

Attention pour le contenu des recettes : il n'y a aucun contrôle en place pour prévenir les utilisateurs mal intentionnés.
